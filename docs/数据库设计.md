# 数据库设计

```mermaid
erDiagram
  users ||--o{ chat_sessions : owns
  chat_sessions ||--o{ chat_messages : contains
  chat_messages ||--o{ message_sources : cites
  users ||--o{ feedbacks : submits
  chat_messages ||--o{ feedbacks : receives
  knowledge_documents ||--o{ knowledge_chunks : splits
  knowledge_chunks ||--o{ message_sources : cited_by
```

## 核心表

- `users`：用户账号、手机号、邮箱、密码哈希。
- `chat_sessions`：每次对话会话。
- `chat_messages`：用户消息与 AI 回复。
- `knowledge_documents`：知识库文档元数据和处理状态。
- `knowledge_chunks`：文档切片，与向量数据库 vector_id 关联。
- `message_sources`：AI 回答引用来源。
- `feedbacks`：点赞、踩、文字反馈。
