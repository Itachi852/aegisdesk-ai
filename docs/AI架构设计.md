# AI 架构设计

## RAG 流程

```mermaid
flowchart TD
  A["用户问题"] --> B["长度与额度校验"]
  B --> C["意图识别"]
  C --> D["携带最近 N 轮上下文"]
  D --> E["Embedding 向量化问题"]
  E --> F["Qdrant Top-K 检索"]
  F --> G{"是否达到相似度阈值"}
  G -- 否 --> H["返回兜底话术"]
  G -- 是 --> I["规则优先级排序与上下文压缩"]
  I --> J["拼接 Prompt"]
  J --> K["LLM 流式生成"]
  K --> L["SSE 返回前端"]
  L --> M["保存消息与引用来源"]
```

## Prompt 设计

系统提示词核心约束：

- 只能基于知识库内容回答。
- 不允许编造知识库中不存在的规则。
- 检索不足时明确说明无法准确回答。
- 回答需要简洁，并说明依据。

## 检索策略

- Top-K：默认 6。
- 相似度阈值：默认 0.5。
- 文档状态过滤：只检索 `ready` 文档。
- 多知识库扩展：先做知识库路由，再在目标知识库内检索。

## 幻觉控制

- 空检索直接兜底。
- 低分片段不进入 Prompt。
- 高优先级业务规则前置。
- 答案保存引用来源，方便人工追溯。
